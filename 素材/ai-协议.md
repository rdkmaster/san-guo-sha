# AI玩家决策协议（droid调用规范）

> 引擎与AI的全部交互契约。规则教材见 `素材/规则-1v1.md`。

## 1. 调用方式

```bash
# 首次调用（教学+决策，建立会话）
droid exec -m glm-5.3-flash -r high -o json -f 局面文件.md   # 工作目录=workspace

# 后续调用（复用会话，AI保留此前全部对局记忆）
droid exec -m glm-5.3-flash -r high -o json -s <sessionId> -f 局面文件.md
```

- **首次调用一股脑给全**：局面文件 = 规则教材全文 + 本协议全文 + 首个决策局面（双方武将技能已含在局面里）。AI无需读任何文件。
- 后续调用只发**当前局面**（会话里已有规则与历史）。历史出牌AI自己记得，不重复提供。
- 输出用 `-o json`：引擎解析其中的 `result`（AI回复）与 `session_id`（会话续接）。
- 工作区 `AGENTS.md` 固化行为约束（禁用工具、输出契约等）。
- 每次调用的输出末尾必须是一个JSON动作块（见§3），引擎从中解析。
- 引擎对输出做合法性校验：非法动作重新询问（同一决策最多重问3次，仍失败则回退本地随机合法动作并记录）。

## 2. 局面文件格式

每次决策，引擎生成如下**半结构化Markdown**（AI视角，只含自己可见的信息）：

```markdown
# 决策请求 #17
**决策类型**: play

## 你的状态
- 武将: **关羽**（体力 3/4）
- 技能:
  - **武圣**：你可以将一张红色牌当【杀】使用或打出。
- 装备: 武器-无 | 防具-无 | +1马-无 | -1马-赤兔（你计算与对手距离-1）
- 判定区: 无
- 手牌 4张:
  | 编号 | 牌名 | 花色点数 | 类型 | 可出 |
  |---|---|---|---|---|
  | #1 | 杀 | ♥4 | 基本牌 | ✓ |
  | #2 | 闪 | ♠3 | 基本牌 | — |
  | #3 | 无懈可击 | ♦Q | 锦囊牌 | — |
  | #4 | 桃 | ♥9 | 基本牌 | — |

## 对手状态
- 武将: **张飞**（体力 2/4）
- 技能:
  - **咆哮**（锁定技）：你使用【杀】无次数限制。
- 装备: 武器-无 | 防具-八卦阵 | +1马-无 | -1马-无
- 判定区: 无
- 手牌: 5张（不可见）

## 公共信息
- 回合: 第5回合（对手回合/你的回合-出牌阶段）
- 当前距离: 你→对手 1（对手→你 1）
- 你本回合已用: 杀 1/1（张飞咆哮使其无限制）| 酒 0/1
- 弃牌堆（最近8张，更早的记不清了）: 过河拆桥、杀♠7、桃♥3、闪电、闪♦J
- 牌堆剩余: 约120张

## 本次决策要求
出牌阶段。可用动作: `play`（使用手牌/发动技能）或 `end`（结束出牌）。
转化提示: 你的红牌可经【武圣】当【杀】使用。
```

### 决策类型与可用动作

| 决策类型 | 时机 | 可用动作 |
|---|---|---|
| `xuanjiang` | 开局选将：从你的3名候选武将中选1名出战（局面文件列出候选与技能全文） | `choose`(choice=候选武将名) |
| `play` | 出牌阶段（循环询问） | `play`(出牌/转化：武圣/龙胆/奇袭/国色) / `activate`(主动技：苦肉/结姻不带card，仁德/青囊带card) / `skill`(制衡) / `sha_combo`(丈八蛇矛两牌当杀) / `end` |
| `respond_sha` | 你被【杀】或【万箭齐发】指定，求【闪】 | `respond`(出闪/龙胆杀/倾国黑色手牌转化) / `refuse`(掉血) |
| `respond_nanman` | 南蛮入侵/决斗轮到你，求打出【杀】 | `respond`(杀/武圣红牌/龙胆闪转化) / `refuse` |
| `dying` | 有人濒死，问你是否给桃 | `tao`(出桃；濒死者自己可用酒；华佗回合外红色牌可当桃) / `refuse` |
| `wuxie` | 锦囊结算前问无懈（MVP只问被影响者一次） | `wuxie`(出无懈) / `refuse` |
| `discard` | 弃牌阶段超手牌上限（吕蒙克己达标时整段跳过） | `discard`(指定弃牌，数量必须精确) |
| `choose` | 五谷选牌 / 火攻展示手牌 / 拆桥·顺牵选区域 / 寒冰剑弃牌选区域 / 雌雄双股剑弃牌 / 青囊选目标(self/opp) / 刚烈让来源选(discard2/hurt) | `choose`(card选牌 或 choice选区域/选项) / `skip`(雌雄：让对方摸1) |
| `guanxing` | 观星分配：一次亮出的牌必须逐张指定位置 | `guanxing`(tops=置于牌堆顶的编号数组, bottoms=置于牌堆底的编号数组，两数组恰好分完所有亮出的牌) |
| `fanjian_suit` | 你是反间目标，选一种花色 | `fanjian_suit`(suit=♥/♠/♣/♦) |

引擎简化项（MVP，AI无需操心）：无懈可击只询问被影响者一次；铁索连环不在牌堆中；方天画戟在1v1中无额外目标可指定（仅作为范围4武器生效）。

## 3. 动作输出契约（AI必须输出的JSON）

每次回复的**最后一行**必须是且仅是一个JSON对象：

```json
{"action": "choose", "choice": "郭嘉"}
{"action": "play", "card": "#1", "targets": ["对手"]}
{"action": "play", "card": "#4", "targets": ["自己"]}
{"action": "play", "card": "#2", "useAs": "杀", "targets": ["对手"]}
{"action": "skill", "skill": "制衡", "cards": ["#1", "#3"]}
{"action": "skill", "skill": "反间"}
{"action": "fanjian_suit", "suit": "♥"}
{"action": "end"}
{"action": "respond", "card": "#2", "useAs": "闪"}
{"action": "refuse"}
{"action": "tao", "card": "#4"}
{"action": "wuxie", "card": "#3"}
{"action": "discard", "cards": ["#1", "#2"]}
{"action": "choose", "card": "#5"}
{"action": "choose", "choice": "equip"}
{"action": "guanxing", "tops": ["#5"], "bottoms": ["#6"]}
{"action": "skip", "skill": "雌雄双股剑"}
{"action": "sha_combo", "cards": ["#1", "#3"]}
{"action": "activate", "skill": "奸雄"}
{"action": "activate", "skill": "火攻", "card": "#2"}
{"action": "activate", "skill": "苦肉"}
{"action": "activate", "skill": "仁德", "card": "#1"}
{"action": "activate", "skill": "青囊", "card": "#2"}
{"action": "activate", "skill": "结姻"}
{"action": "skip", "skill": "集智"}
{"action": "daodao_sha"}
{"action": "daodao_give"}
```

字段约定：
- `card` / `cards`：局面表格中的编号（`#N`，含"候选牌"区的编号）。
- `useAs`：转化技使用（如武圣红牌当杀、龙胆杀闪互转、国色方块当乐不思蜀），引擎校验转化合法性。
- `skill`：技能名（制衡/奸雄/集智/火攻/苦肉/仁德/青囊/结姻等）。
- `choice`：区域选择（hand/equip/judge）、选项（self/opp=青囊目标、discard2/hurt=刚烈选项）或选将武将名（xuanjiang），按局面下发使用。
- `guanxing`：`tops`/`bottoms` 填"候选牌"区的编号数组，两数组必须恰好分完亮出的牌（重复或遗漏→重问，3次失败后全部置于牌堆顶）。
- `targets`：合法目标名（1v1只有`自己`/`对手`，引擎已按局面列出，通常可省略）。
- **可出列**：手牌表的"可出"列是引擎根据技能/手牌/装备/距离确定性计算的结果（✓=合法动作已包含，—=当前不可出）。`sha_combo` 组合的两张牌必须互不相同且都在引擎下发的合法池内，引擎校验不通过会重问。
- 除最后JSON行外，AI可先输出简短思考（≤3行），引擎只解析最后一行。

## 4. 决策参考原则（写给AI的策略提示）

1. 保命优先：体力≤2时优先留【闪】【桃】，评估对手手牌数估算其威胁。
2. 技能即战力：看清双方技能再决策——对手是张飞（咆哮）时多留闪；你是赵云时杀闪可互转、手牌价值翻倍；你是吕布时你的杀价值更高。
3. 转化技用好转化：关羽红牌都是杀（红色闪/桃也能杀）、甘宁黑牌都是过河拆桥；转化牌同样计入次数限制，别浪费普通杀的次数。
4. 手牌管理：弃牌阶段保留【杀】【闪】【桃】等高价值牌，先弃多余装备与低价值锦囊。
5. 装备：武器优先装（扩大射程），八卦阵/仁王盾性价比高；对手装八卦阵时，青釭剑/火杀/雷杀价值上升。
6. 节奏与斩杀：对手体力1时，保留火杀/酒杀/决斗/古锭刀组合一击必杀。
7. 判定博弈：自己判定区有乐不思蜀/闪电时留无懈可击自救（锦囊结算前可用无懈抵消）。
8. 反间博弈：你是反间目标时，选你判断对手最不可能给出的花色（每花色各1/4，但可结合已见弃牌推测）；你是周瑜时，优先交低价值手牌，赌花色命中造成1点伤害。

## 5. 引擎侧容错

- 解析：取AI输出中最后一个 `{...}` JSON块；解析失败→重问。
- 合法性：目标/次数/距离/牌存在性由引擎校验，非法→附错误重问。
- 超时/崩溃：单次调用超时上限300秒；连续失败3次→该决策点用本地兜底策略（随机合法动作）并在日志标记。
- 日志：每次调用完整记录 prompt/输出/耗时 到 `_logs/`，便于复盘AI水平。
