# 三国杀 1v1 游戏规则（AI教学版）

> 本文档是AI玩家的完整规则教材。引擎已强制执行所有合法性约束，AI只需依据本文档做出最优决策。
> 版本: 基于官方1v1模式简化，牌堆使用"标准版+EX+军争篇"160张，武将带技能。

## 0. 胜负目标

将对手体力值降至0（对手死亡）即获胜。1v1无身份、无奖惩。

## 1. 对局准备

1. 双方各随机分配一名武将（带技能，见§9），体力值=武将体力上限。
2. 牌堆洗匀（160张，其中**铁索连环6张在1v1中不使用**，实际154张）。双方各摸**4张**起手牌。
3. 随机决定先手。**先手第一回合摸牌阶段少摸一张牌（摸1张），出牌阶段正常进行**（官方1v1平衡规则）。

## 2. 回合流程（轮流进行）

每个回合依次经过以下阶段：

| 阶段 | 内容 |
|---|---|
| 准备阶段 | 触发"准备阶段"类技能 |
| 判定阶段 | 依次结算判定区里的延时锦囊（见§6）；拥有改判技能（如鬼才）的武将可在此时替换判定牌 |
| 摸牌阶段 | 从牌堆顶摸2张（先手第一回合只摸1张；摸牌类技能在此追加/变动） |
| 出牌阶段 | 任意次使用手牌与主动技能（受§4次数限制），或宣布结束 |
| 弃牌阶段 | 手牌数超过当前体力值时，弃置多余的手牌 |

牌堆摸空时，将弃牌堆洗匀作为新牌堆。

## 3. 距离与攻击范围

- 1v1中双方坐位数恒定，**基础距离为1**。
- **-1马**：你计算与其他角色的距离-1（影响你发起的牌的距离判定）。
- **+1马**：其他角色计算与你的距离+1（影响对手攻击你）。
- **攻击范围** = 1 + 武器加成（见§7）。【杀】只能对攻击范围内、且距离足够的对手使用。

## 4. 出牌阶段规则

- 【杀】每回合限使用1张（装备【诸葛连弩】或拥有"咆哮"类技能后无限制）。
- 其余牌无使用次数限制（【酒】每回合限1张）。
- **转化技**（如武圣/龙胆/奇袭）：可将满足条件的手牌"当"成另一张牌使用或打出——视为使用该目标牌，计入对应次数限制。
- 使用【杀】：指定对手为目标，对手可出【闪】抵消。
- 装备牌：进入自己对应装备槽，替换时旧装备进入弃牌堆（每槽最多1件：武器/防具/+1马/-1马）。
- 延时锦囊：不直接结算，置入对手（或自己，【闪电】）的判定区，每名角色判定区每种延时锦囊最多1张。
- **主动技能**：消耗相应代价发动（见§9），与出牌可穿插进行。

## 5. 基本牌

| 牌 | 效果 |
|---|---|
| 杀(普通/火/雷) | 对手需出1张【闪】，否则受到1点伤害（火/雷仅影响与特定技能/防具的互动，白板对局中等同普杀，但火杀可被【藤甲】+1伤害） |
| 闪 | 仅用于响应【杀】（及万箭齐发等），不能主动使用 |
| 桃 | 仅自己回合内可主动使用：回复1点体力；出牌阶段体力满时无用 |
| 酒 | 本回合下一张【杀】伤害+1（叠加于响应结果之后）；或濒死时当【桃】自救（每回合限1次主动使用） |

## 8. 延时锦囊与判定

置于判定区的牌，在持有者**判定阶段**翻开牌堆顶1张作为判定牌，然后：

| 牌 | 判定结果 |
|---|---|
| 乐不思蜀（红桃解除） | 判定牌非红桃：跳过本回合**出牌阶段** |
| 兵粮寸断（梅花解除） | 判定牌非梅花：跳过本回合**摸牌阶段**（注意：使用时目标须在距离1以内） |
| 闪电（♠2~♠9命中） | 判定牌为黑桃2-9：受到3点雷电伤害；否则传递给对手（置于其判定区），不造成伤害 |

判定牌（及因此弃置的延时锦囊）进入弃牌堆。

## 9. 武将技能系统

技能分三类，AI会同时知道**自己和对手**的全部技能文本（技能是公开信息）：

- **锁定技**：满足条件自动触发，无需AI决策（如咆哮、奇才）。
- **触发技**：满足条件时引擎询问AI是否发动（如奸雄、反馈、刚烈）。
- **主动技**：出牌阶段由AI选择发动（如制衡、奇袭、武圣、龙胆），与出牌穿插进行，计入各自发动次数限制。

## 10. 受伤、濒死与死亡

1. 受到N点伤害：体力值-N。
2. 体力值≤0进入**濒死状态**：从当前回合角色开始，依次询问是否使用【桃】（自己可用任意【桃】/【酒】自救）。每张【桃】回复1点体力。
3. 体力回复至>0：脱离濒死。
4. 无桃可救：死亡，游戏结束，对手获胜。
5. 白银狮子在受伤结算时将大于1点的伤害减至1点；1点伤害不受影响（防不了普通杀）。

## 11. 引擎强制约束（AI无需操心）

以下由引擎保证，AI决策时只需给出意图：
- 动作合法性（次数限制、目标合法性、距离）
- 手牌隐私（AI只能看到自己的手牌，对手仅手牌数量）
- 判定/洗牌随机性
- AI输出非法动作时引擎会驳回并要求重新决策
